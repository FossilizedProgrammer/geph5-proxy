# geph5-proxy

[English](README.md) | [فارسی](README.fa.md) | **Русский**

Автономный клиент Geph5, который — в отличие от VPN — не захватывает всю
систему, а раздаёт обычный **локальный SOCKS5- и/или HTTP-прокси**. Создайте
аккаунт, выберите страну, настройте приложения на прокси — готово.

Работает на Linux и Windows. Linux-бинарник полностью статический.

> **Об этом репозитории:** здесь находится полное исходное дерево Geph5
> (брокер, мосты, exit-ы, библиотеки — описание апстрим-проекта в
> [README.geph5.md](README.geph5.md)) плюс инструмент `binaries/geph5-proxy`,
> который описывает этот README. Готовые бинарники — на странице
> [Releases](../../releases); собрать свои можно через
> `./build-static.sh all`.

## Быстрый старт

```bash
# 1. Создать аккаунт (код сохраняется автоматически)
./geph5-proxy signup

# 2. Посмотреть доступные страны
./geph5-proxy countries                  # все
./geph5-proxy countries --level free     # только бесплатные

# 3. Подключиться (SOCKS5 на 127.0.0.1:9909, HTTP на 127.0.0.1:9910)
./geph5-proxy run --country NL

# 4. Пользоваться
curl --proxy socks5h://127.0.0.1:9909 https://api.ipify.org
curl --proxy http://127.0.0.1:9910   https://api.ipify.org
```

## Команды

### `signup`

Создаёт новый аккаунт Geph: решает proof-of-work загадку, регистрируется и
печатает код аккаунта. Код сохраняется в файл аккаунта (см. `--account-file`),
чтобы последующие команды подхватывали его автоматически.

| Опция | Описание |
|---|---|
| `--account-file <PATH>` | Куда сохранить код аккаунта |
| `--upstream <URL>` | Доступ к брокеру через восходящий прокси |

### `login`

Проверяет код аккаунта у брокера и снова сохраняет его.

| Опция | Описание |
|---|---|
| `--secret <CODE>` | Проверяемый код аккаунта (по умолчанию: сохранённый) |
| `--account-file <PATH>` | Файл для чтения/сохранения кода |
| `--upstream <URL>` | Доступ к брокеру через восходящий прокси |

### `countries`

Список стран выхода: количество exit-ов, бесплатный ли уровень и города.

| Опция | Описание |
|---|---|
| `--level <all\|free\|plus>` | Только exit-ы уровня аккаунта (по умолчанию: `all`) |
| `--upstream <URL>` | Доступ к брокеру через восходящий прокси |

### `run`

Подключается к exit-у Geph и раздаёт локальный прокси до Ctrl-C.

| Опция | Описание |
|---|---|
| `--country <CC>` | Двухбуквенный код страны (`NL`, `DE`, …) или `auto` (по умолчанию) |
| `--city <NAME>` | Ограничить городом из `countries` (требует `--country`) |
| `--exit <HOST/PUBKEY>` | Подключиться к конкретному exit-у вместо выбора страны |
| `--secret <CODE>` | Код аккаунта (по умолчанию: сохранённый, затем запрос) |
| `--socks <SPEC>` | SOCKS5-слушатель: `PORT`, `HOST:PORT` или `none` (по умолчанию: `9909`) |
| `--http <SPEC>` | HTTP-слушатель: `PORT`, `HOST:PORT` или `none` (по умолчанию: `9910`) |
| `--share-lan` | Слушать на `0.0.0.0`, чтобы устройства локальной сети тоже могли пользоваться |
| `--cache <PATH>` | Путь к SQLite-кэшу (по умолчанию: `<cache-dir>/geph5-proxy/db`) |
| `--account-file <PATH>` | Файл, из которого читается код аккаунта |
| `--upstream <URL>` | Сначала весь исходящий трафик идёт через восходящий прокси |

## Глобальные опции

Работают до или после любой команды:

| Опция | Описание |
|---|---|
| `--account-file <PATH>` | Где хранится/читается код аккаунта (по умолчанию: `<config-dir>/geph5-proxy/account.txt`, права 600) |
| `--upstream <URL>` | Прокси, через который идёт *собственный* трафик Geph (брокер + тоннели) |

### Форматы URL восходящего прокси

```
socks5://host:port
socks5://user:pass@host:port
http://host:port
http://user:pass@host:port
```

Позволяет встроить Geph в уже имеющийся прокси (другой VPN, Tor, корпоративный
прокси и т.д.). Примечания:

- Восходящий прокси должен разрешать CONNECT (HTTP) или произвольные
  назначения (SOCKS5) на высоких портах — мосты Geph используют не только
  порт 443. Некоторые локальные прокси (например, некоторые сборки Psiphon)
  разрешают CONNECT только к порту 443 и для самого тоннеля не подойдут.
- IPv6-адреса мостов доступны, только если восходящий прокси поддерживает IPv6.

## Примеры адресов слушания

```bash
# Только этот компьютер (по умолчанию)
./geph5-proxy run --socks 9909 --http 9910

# Вся локальная сеть (без аутентификации — пользоваться сможет кто угодно!)
./geph5-proxy run --share-lan --socks 1080 --http 8080

# Только SOCKS5, конкретный адрес
./geph5-proxy run --socks 192.168.1.9:1080 --http none
```

## Файл аккаунта

По умолчанию код аккаунта лежит в `<config-dir>/geph5-proxy/account.txt` с
правами `0600`. Переопределить расположение везде можно через
`--account-file`:

```bash
./geph5-proxy signup --account-file ~/my-geph-account
./geph5-proxy --account-file ~/my-geph-account run --country auto
```

Порядок чтения кода в `login`/`run`: `--secret` → `--account-file` → путь по
умолчанию → ручной ввод.

## Сборка из исходников

```bash
./build-static.sh all      # статический Linux + Windows .exe в dist/
PKG=geph5-proxy ./build-static.sh linux
```

Требования: тулчейн Rust, gcc/make/perl; для кросс-сборки Windows также
mingw-w64 (скрипт сам заготавливает исходники Rust std).

## Замечания по безопасности

- `--share-lan` открывает **неаутентифицированный** прокси всей локальной сети.
- Код аккаунта — bearer-секрет: любой, у кого он есть, владеет аккаунтом.
- Это неофициальная сборка; подключается к официальным брокерам и exit-ам Geph.
