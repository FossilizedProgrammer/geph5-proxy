# geph5-proxy

[English](README.md) | **فارسی** | [Русский](README.ru.md)

یک کلاینت مستقل Geph5 که — برخلاف حالت VPN — کل سیستم را تصرف نمی‌کند، بلکه
یک **پروکسی محلی SOCKS5 و/یا HTTP** سرو می‌کند. اکانت بسازید، کشور را انتخاب
کنید، برنامه‌ها را به پروکسی وصل کنید — تمام.

روی لینوکس و ویندوز کار می‌کند. باینری لینوکس کاملاً استاتیک است.

> **درباره این مخزن:** کامل سورس Geph5 (بروکر، پل‌ها، خروجی‌ها، کتابخانه‌ها —
> توضیحات پروژه اصلی در [README.geph5.md](README.geph5.md)) به‌علاوه ابزار
> `binaries/geph5-proxy` که همین مستندات آن است، در اینجاست. باینری‌های آماده
> را از صفحه [Releases](../../releases) بگیرید؛ یا با
> `./build-static.sh all` خودتان بسازید.

## منشاء و سلب مسئولیت

**این یک کلاینت غیررسمی است.** مشتقِ تغییریافته‌ای از کلاینت متن‌باز
[Geph5](https://github.com/geph-official/geph5) (نوشته‌شده به زبان Rust توسط
پروژه گف) است، با امکانات اضافه مثل حالت پروکسی مستقل SOCKS5/HTTP، زنجیره
پروکسی بالادستی و مدیریت اکانت از خط فرمان.

- این پروژه **نه وابسته به پروژه رسمی گف است، نه تأییدشده و نه مرتبط با
  اپراتورهای آن**. درخواست‌های پشتیبانی، قطعی‌ها یا سؤالات مربوط به خود
  شبکه باید از کانال‌های رسمی گف پیگیری شود.
- نام **«گف» (Geph)** علامت تجاری متعلق به مالکان آن است. هیچ‌حقی برای
  استفاده از این علامت تجاری از این پروژه داده نمی‌شود؛ این بایلد نباید
  به‌صورت محصول رسمی گف معرفی شود.
- کد اصلی Geph5 تحت لایسنس **Mozilla Public License 2.0 (MPL-2.0)** و برخی
  کتابخانه‌های پایین‌سطح تحت لایسنس **ISC** منتشر شده است. این نسخه
  تغییریافته همچنان تابع همان لایسنس‌هاست: اگر باینری یا نسخه تغییریافته
  حاوی کد MPL-2.0 توزیع می‌کنید، باید فایل‌های منبع MPL-2.0 تغییریافته
  مربوطه را در اختیار گیرندگان بگذارید و همه اعلان‌های کپی‌رایت و لایسنس
  را حفظ کنید. متن کامل لایسنس‌ها در
  [مخزن اصلی](https://github.com/geph-official/geph5) موجود است.
- **بدون ضمانت:** نرم‌افزار «as is» و بدون هیچ ضمانتی ارائه می‌شود، همان‌طور
  که در لایسنس‌های MPL-2.0 و ISC آمده است. استفاده با مسئولیت خودتان.
- اتصال از طریق بروکرها و خروجی‌های رسمی گف فراهم می‌شود که این نرم‌افزار
  مالک یا کنترل‌کننده آن‌ها نیست و در دسترس بودن، محدودیت‌ها (از جمله سقف
  پهنای باند رایگان) و سیاست‌هایشان ممکن است هر زمان تغییر کند. کد اکانت
  یک راز bearer برای آن شبکه است؛ مانند آن رفتار کنید.

## شروع سریع

```bash
# ۱. ساخت اکانت (کد به‌صورت خودکار ذخیره می‌شود)
./geph5-proxy signup

# ۲. دیدن کشورهای قابل اتصال
./geph5-proxy countries                  # همه
./geph5-proxy countries --level free     # فقط رایگان

# ۳. اتصال (SOCKS5 روی 127.0.0.1:9909 و HTTP روی 127.0.0.1:9910)
./geph5-proxy run --country NL

# ۴. استفاده
curl --proxy socks5h://127.0.0.1:9909 https://api.ipify.org
curl --proxy http://127.0.0.1:9910   https://api.ipify.org
```

## دستورات

### `signup` — ساخت اکانت

یک اکانت گف جدید می‌سازد: معمای اثبات کار را حل می‌کند، ثبت‌نام می‌کند و کد
اکانت را چاپ می‌کند. کد در فایل اکانت (ببینید `--account-file`) ذخیره می‌شود
تا دستورات بعدی خودکار از آن استفاده کنند.

| آرگومان | توضیح |
|---|---|
| `--account-file <مسیر>` | کجا کد اکانت ذخیره شود |
| `--upstream <URL>` | دسترسی به بروکر از طریق یک پروکسی بالادستی |

### `login` — ورود/اعتبارسنجی

کد اکانت را با بروکر چک کرده و دوباره ذخیره می‌کند.

| آرگومان | توضیح |
|---|---|
| `--secret <کد>` | کد اکانت برای اعتبارسنجی (پیش‌فرض: کد ذخیره‌شده) |
| `--account-file <مسیر>` | فایلی که کد از آن خوانده/در آن ذخیره می‌شود |
| `--upstream <URL>` | دسترسی به بروکر از طریق پروکسی بالادستی |

### `countries` — لیست کشورها

کشورهای خروجی، تعداد exitها، رایگان بودن یا نبودن و شهرها را نشان می‌دهد.

| آرگومان | توضیح |
|---|---|
| `--level <all\|free\|plus>` | فقط exitهای همان سطح اکانت (پیش‌فرض: `all`) |
| `--upstream <URL>` | دسترسی به بروکر از طریق پروکسی بالادستی |

### `run` — اتصال و اجرا

به یک خروجی گف وصل شده و یک پروکسی محلی سرو می‌کند تا با Ctrl-C بسته شود.

| آرگومان | توضیح |
|---|---|
| `--country <CC>` | کد دوحرفه‌ای کشور (`NL`، `DE`، …) یا `auto` (پیش‌فرض) |
| `--city <نام>` | محدود کردن به شهری از لیست `countries` (نیازمند `--country`) |
| `--exit <HOST/PUBKEY>` | اتصال مستقیم به یک exit مشخص به‌جای انتخاب کشور |
| `--secret <کد>` | کد اکانت (پیش‌فرض: کد ذخیره‌شده، سپس پرسش) |
| `--socks <SPEC>` | نشانی SOCKS5: `PORT`، `HOST:PORT`، یا `none` (پیش‌فرض: `9909`) |
| `--http <SPEC>` | نشانی HTTP: `PORT`، `HOST:PORT`، یا `none` (پیش‌فرض: `9910`) |
| `--share-lan` | بایند روی `0.0.0.0` تا دستگاه‌های شبکه محلی هم بتوانند استفاده کنند |
| `--cache <مسیر>` | مسیر کش SQLite (پیش‌فرض: `<cache-dir>/geph5-proxy/db`) |
| `--account-file <مسیر>` | فایلی که کد اکانت از آن خوانده می‌شود |
| `--upstream <URL>` | همه ترافیک خروجی ابتدا از یک پروکسی بالادستی رد شود |

## آرگومان‌های سراسری

این‌ها قبل یا بعد از هر دستوری کار می‌کنند:

| آرگومان | توضیح |
|---|---|
| `--account-file <مسیر>` | محل ذخیره/خواندن کد اکانت (پیش‌فرض: `<config-dir>/geph5-proxy/account.txt` با دسترسی 600) |
| `--upstream <URL>` | پروکسی‌ای که کل ترافیک خودِ گف (بروکر + تونل‌ها) از آن رد می‌شود |

### قالب‌های URL پروکسی بالادستی

```
socks5://host:port
socks5://user:pass@host:port
http://host:port
http://user:pass@host:port
```

با این قابلیت، گف را از پروکسی‌ای که از قبل دارید زنجیره می‌کنید (یک VPN دیگر،
Tor، پروکسی سازمانی و…). نکات:

- پروکسی بالادستی باید CONNECT (برای HTTP) یا مقاصد دلخواه (برای SOCKS5) روی
  پورت‌های بالا را قبول کند — پل‌های گف فقط پورت 443 استفاده نمی‌کنند. برخی
  پروکسی‌های محلی محدود (مثل بعضی بیلدهای Psiphon) فقط CONNECT به پورت 443 را
  قبول دارند و برای خود تونل کار نمی‌کنند.
- آدرس‌های IPv6 پل‌ها فقط وقتی قابل استفاده‌اند که پروکسی بالادستی IPv6 داشته باشد.

## مثال‌های نشانی گوش دادن

```bash
# فقط همین دستگاه (پیش‌فرض)
./geph5-proxy run --socks 9909 --http 9910

# کل شبکه محلی (بدون احراز هویت — هرکسی در شبکه می‌تواند استفاده کند!)
./geph5-proxy run --share-lan --socks 1080 --http 8080

# فقط SOCKS5، نشانی مشخص
./geph5-proxy run --socks 192.168.1.9:1080 --http none
```

## فایل اکانت

به‌صورت پیش‌فرض کد اکانت در `<config-dir>/geph5-proxy/account.txt` با دسترسی
`0600` ذخیره می‌شود. با `--account-file` در همه جا محل آن را عوض کنید:

```bash
./geph5-proxy signup --account-file ~/my-geph-account
./geph5-proxy --account-file ~/my-geph-account run --country auto
```

ترتیب خواندن کد در `login`/`run`: اول `--secret`، سپس `--account-file`، سپس
مسیر پیش‌فرض، سپس پرسش دستی.

## بیلد از سورس

```bash
./build-static.sh all      # لینوکس استاتیک + ویندوز در dist/
PKG=geph5-proxy ./build-static.sh linux
```

پیش‌نیازها: ابزار Rust، gcc/make/perl؛ برای بیلد متقاطع ویندوز هم mingw-w64
(اسکریپت خودش منبع std را آماده می‌کند).

## نکات امنیتی

- `--share-lan` یک پروکسی **بدون احراز هویت** را در اختیار کل شبکه محلی می‌گذارد.
- کد اکانت یک راز bearer است: هرکس آن را داشته باشد مالک اکانت است.
- این یک بایلد غیررسمی است؛ به بروکرها و خروجی‌های رسمی گف وصل می‌شود.

## لایسنس

کد مشتق‌شده از Geph5: **MPL-2.0** (برخی کتابخانه‌های پایین‌سطح: **ISC**).
این توزیع تغییریافته منطبق با همین لایسنس‌هاست؛ گیرندگان باینری حق
دریافت فایل‌های منبع MPL-2.0 تغییریافته مربوطه را دارند. بخش «منشاء و
سلب مسئولیت» بالا را ببینید.
